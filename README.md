🏦 BankCore — Sistema Bancário REST

A proposta é desenvolver um backend bancário completo, com complexidade suficiente para exercitar conceitos que aparecem em projetos profissionais.

O objetivo não é apenas fazer CRUD. O sistema terá regras de negócio, consistência financeira, concorrência, idempotência, auditoria, segurança e matemática financeira.
